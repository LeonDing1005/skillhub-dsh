# @deepseek-ai/dsh-client-ui-skill-center

[English](README.md) | 中文

面向标准化社区技能目录的原生技能中心页面。该插件注册侧边栏底部操作和一个 `shell.page` 中央界面，在目录打开时保留周围的 workspace 与 Session shell。选择或创建 Session 会返回会话。

“社区技能”标签页可用，“我的技能”保持可见但禁用。确定性的加载、空、带重试的失败和有数据状态共用一个稳定卡片网格。卡片展示命名空间/slug 标识、标题、描述、发布者、精确版本、标签、星标数、下载数以及 Host 派生的“新上架”标记；不展示浏览量或任何上游专用字段。

页面只通过标准 connection 服务调用 `skill.communityList`。它不会接收 SkillHub 凭据、基础 URL、上游响应类型或 Host 路径，也不提供安装或调用操作。

## 模型体验

无，因为该浏览器发现界面不注册任何面向模型的内容。

#### KV Cache 影响

无。

## 已知限制与延后工作

- “我的技能”、筛选、分页控件、详情页和安装不在本基础功能中启用。
