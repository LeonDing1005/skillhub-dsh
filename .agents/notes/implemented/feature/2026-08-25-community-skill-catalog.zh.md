# Agent Note: 社区技能目录基础

Status: implemented

[English](2026-08-25-community-skill-catalog.md) | 中文

## 问题

浏览器已有可调用的本地 Skill 菜单，但没有原生界面用于发现固定 SkillHub 部署中的社区技能。若把上游条目当作普通 `ctx.skills` 条目，尚未安装的远程内容会变得可调用，上游概念会进入浏览器代码，而且存在多个注册表实例时，相同的命名空间/slug/版本元组将无法区分。

## 决定

社区发现是独立的 Host 能力。`@deepseek-ai/dsh-skill-marketplace` 拥有一个已配置的 SkillHub Registry Instance，验证固定的已部署 OpenAPI 与响应 fixture，用精确版本详情补全列表行，并输出 dsh 自有的卡片值。每个标识由独立配置的不透明 `registryInstanceId`、命名空间、slug 和精确版本组成。适配器拥有基于 Host 时钟七天的“新上架”规则；缺失、无效、未来或更早的发布时间都不会标记为新。

`skill.communityList` 通过现有 API gateway 和 connection 载体传递该标准化值。其浏览器 schema 不含基础 URL、凭据、上游类型、Host 路径或浏览量。现有按 Session 寻址的 `skill.list` 仍是已安装且可调用的目录；marketplace 绝不注册到 `ctx.skills`，也不公开安装或调用操作。

`skill.communityGet` 返回一个不可变标识对应的 dsh 自有详情。适配器组合上游技能详情、不超过可配置数量上限的完整分页版本列表、精确版本元数据、文件列表、有字节上限的原始 `SKILL.md` 和精确 `resolve` 结果，并拒绝命名空间、slug 或版本的任何不一致。只有已解析发布元数据的 `metadata.examplePrompt` 是字符串时才包含示例提示词。官方本地命令严格采用 `skillhub install <slug> --namespace <namespace> --version <version>` 形式，并要求每个插值 token 都符合 CLI token 语法。

精确制品字节使用 Host-only 的 `GET /api/skill.download` 界面，而不走 JSON-RPC。浏览器把一次同源 GET 交给原生下载管理器，在不把归档保留于浏览器内存的情况下维持流式传递。Host 解析请求版本，在转发归档的同时解码，并在有界的任一中央目录条目未引用已核验本地文件头，或任一文件的大小与 SHA-256 不匹配精确发布文件列表时使流失败。响应提供经过安全处理且含规范名称/版本的附件文件名。浏览和下载都不会写安装收据或注册该发布版本。

marketplace 按标准化后的查询、标签、排序、页码和分页大小缓存完整列表页。默认情况下，成功页面在五分钟内保持新鲜，并在二十四小时内可作为陈旧回退；两个时间窗口都可配置。超过陈旧窗口后的可用性故障会成为带类型的不可用结果；无效 Registry 响应会直接失败，避免陈旧数据掩盖 API 不兼容。每个缓存键的 generation 防止较早的并发请求替换较新的缓存条目。HTTP 429 重试使用已配置的本地指数调度，受固定次数与 Host 计时器范围约束，并忽略上游 `Retry-After` 调度。

原生 `ui-skill-center` 插件贡献一个侧边栏操作和一个 `shell.page` 中央界面。“社区技能”可用，“我的技能”可见但禁用，页面拥有确定性的加载、空、失败/重试、陈旧、不可用和有数据状态。页面对搜索执行防抖，把标签视为分类，并在搜索、分类或排序变化时重置分页。增量分页在下一页等待或可重试时保留已有卡片。每个请求都带有代次和中止信号，因此被取代的响应无法覆盖更新结果。卡片展示稳定标识、标题、描述、发布者、标签、精确版本、星标数、下载数和 Host 派生的“新上架”标记。页面可见时，`AppFrame` 会隐藏会话与详情元素，但保持两个组件树挂载；选择或创建 Session 会调用 `showConversation()`，并重新显示同一份 Session 状态。

选择卡片会打开可中止的精确发布详情对话框，包含“在 dsh 中使用”和“本地 / 第三方安装”两种模式。标题区只显示规范名称、发布者、精确版本、星标数和下载数。本地模式显示带复制反馈的官方命令并提供 Host 下载；dsh 模式只在 Host 提供示例时显示示例。共享 Markdown 渲染器让原始 HTML 保持字面文本，为本预览抑制远程图片，并把代码和无断点长文本限制在有界滚动区中。模态框限制焦点范围，可通过 Escape 或取消关闭，并把焦点还给选中的卡片。

## 考虑过的替代方案

**把远程条目直接注册到 `ctx.skills`。** 这会抹去发现与安装的区别，并在安装策略、信任决策、本地持久化格式或更新生命周期尚不存在时，使远程内容可以调用。

**让浏览器直接调用 SkillHub。** 这会把部署标识、凭据、上游响应变化和网络策略暴露给呈现代码。Host 标准化使浏览器协议保持稳定且由 dsh 拥有。

**只用命名空间和 slug 作为完整标识。** 这些字段会在不同注册表实例和版本之间冲突。即使首个组合只使用一个固定上游，稳定的注册表实例 id 和精确版本仍保持显式。

**在 React 中派生“新上架”。** 浏览器时钟和解析会使同一条目在不同客户端呈现不同结果。验证 `publishedAt` 的 Host 拥有时间判断，并只发送一个布尔值。

**分别缓存每个浏览器控件。** 搜索、分类、排序和分页共同标识一个上游结果。部分缓存键可能显示由其他控件生成的页面，因此 Host 使用完整的标准化请求。

**在 HTTP 429 后遵循 `Retry-After`。** 任意的上游延迟可能让 Host 请求和资源保留到超出部署的本地策略。适配器改为拥有有界的重试调度。

**通过 JSON-RPC 传递制品。** 二进制响应体不属于 JSON 值 schema，而且会要求缓冲或 base64 膨胀。Host-only 的 GET 界面保留 Host 流式传递，并使浏览器 API 不含上游 URL。

**从 `SKILL.md` 推断示例。** 标题或正文块不是权威元数据，不同解析器可能选择不同文本。可选区段只遵循 `metadata.examplePrompt`，否则不显示。

## 后果

已发布 Web 组合可以搜索、筛选、排序、分页浏览并检查真实社区目录，而不授予调用能力，也不泄露 Host 配置。在有界的上游故障期间，目录仍可使用 Host 最近成功的结果；过期数据会明确失败。为了取得已部署 API 缺失的精确版本字段，列表补全会为每个可见行增加一对请求；打开对话框会在已配置的源字节数与版本数量上限内发送精确发布读取请求集。“我的技能”、安装、注册表聚合和更新策略保持缺席，不会被浏览或本地下载暗示为已存在。组件测试固定目录状态、详情成功与可选示例行为、预览安全性、键盘行为和注册释放，固定 fixture 固定上游与 dsh wire 字段。浏览器组合测试启动已发布 Loader 树，通过 Host 适配器访问确定性的 HTTP Registry Instance，并覆盖组合控件、分页重试、取消、限流、离线陈旧数据、带类型的过期结果、响应式布局、精确发布对话框视觉状态和真实的已核验浏览器下载路径。
